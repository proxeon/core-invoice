# core-invoice-fixtures

In-memory constructors: PINT-MY SST (`SA`), Peppol VAT, and authored `pint_gst_sr`. These are **not** an official CEN / Peppol / PINT corpus.

Official XML for `cargo test` is git-tracked [`testdata/`](../../testdata/) (EUPL/Peppol terms). It is **not** packaged on crates.io. PINT Billing 1.1.2 has no official invoice XML; `pint_gst_sr` is MIT authored, not an oracle.

Full guide: <https://github.com/proxeon/core-invoice>
